## 👨‍💻 About Me

I'm a cloud and platform engineering professional with **12+ years of experience**, passionate about building secure, scalable and reliable infrastructure through automation.

I enjoy solving complex infrastructure challenges, improving developer experience and building reusable platform capabilities that make software delivery more efficient.

- ☁️ **Cloud Engineering:** Microsoft Azure, AKS and cloud-native infrastructure
- ☸️ **Platform Engineering:** Kubernetes, Helm, Istio and platform automation
- 🏗️ **Infrastructure as Code:** Terraform, Terragrunt and Bicep
- 🔄 **CI/CD & GitOps:** Azure DevOps, GitHub Actions, Flux and Argo CD
- 🔐 **Cloud Security:** Managed identities, workload identity, Key Vault and Kubernetes RBAC
- 📊 **Observability & SRE:** Prometheus, Grafana, Loki, OpenTelemetry and reliability engineering
- 🚀 **Exploring:** Backstage, Crossplane, AI-powered operations and internal developer platforms
- 🧰 **Automation:** Python, PowerShell, Bash and infrastructure tooling

💡 My philosophy: **Automate the repetitive, secure the foundations and make the platform easy for developers to use.**
